# Справочник и карта

Основной источник: https://masterwork.wiki/lu4/ (Gamma).
18.10.2026 попытки чтения главной страницы и поиска через доступный web fetch вернули HTTP 403.
Импорт не выполнен. Не обходить блокировку циклом повторных запросов. Следующий шаг: доступный экспорт или разрешённый браузерный сбор с паузами и checkpoint.

В каталоге хранить NPC ID, имя, уровень, локацию, координаты XYZ, min/max респауна, дроп item ID + количество + вероятность, URL источника и время проверки UTC.
Не выводить точные шансы из частот наблюдений. Не превращать групповой шанс в шанс предмета без подтверждения семантики источника. Не подставлять нулевые координаты/шансы при отсутствии данных.

Формат файла: {"schemaVersion":1,"bosses":[...]}. Boss соответствует src/domain/model.ts.
Проверка: `npm run validate:catalog -- path/to/catalog.json`.
Пустой каталог допустим, но не считается завершённым импортом.
В дальнейшем: staging → проверка дубликатов, координат и выборочных карточек → транзакционный upsert с diff-отчётом.

Карта: сохранить исходное изображение, URL, размер и версию. Калибровать преобразование игровых X/Y в пиксели по минимум трём независимым контрольным точкам; проверить направление осей и точки вне границ. Не использовать учебные координаты из demo.ts.
