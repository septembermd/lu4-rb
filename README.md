# LU4 RB

Закрытая разведка рейдовых боссов для кланов LU4: карта, ручные таймеры, наблюдения IKAR и подписка на клан.

## Состояние v0.1
Работают локальный React-интерфейс и явно помеченное демо: поиск, фильтр источников, выбор точки, карточка дропа, ручные отметки и расчёт окон. Доменное ядро содержит проверку прав и фильтрацию клановых/платных наблюдений; это ещё **не серверная авторизация**.

Подготовлены миграция PostgreSQL, валидатор каталога, спецификация IKAR и план реализации.
Реальная карта/справочник ещё не импортированы (источник вернул 403). API, логин, постоянное хранение, биллинг и IKAR-адаптер пока не реализованы. Не использовать для продажи production-доступа.

## Локальный запуск
Node.js 24+.

```sh
npm ci
npm run dev
```

Открыть адрес Vite. Кнопка «Проверить демо» включает синтетические данные. Отметки остаются только в памяти вкладки. Текущее время отображается в часовом поясе браузера, доменные даты передаются в UTC.

```sh
npm test
npm run build
```

## Структура
- `src/domain` — типы, таймеры и правила доступа, используемые будущим API.
- `src/data/demo.ts` — исключительно синтетические fixtures.
- `db/001_initial.sql` — основа постоянного хранения; приватные таблицы default-deny RLS, runtime-политики ещё не реализованы.
- `docs/DECISIONS.md` — согласованные правила продукта.
- `docs/IKAR-API.md` — контракт будущего агента.
- `docs/DATA-IMPORT.md` — источники и процесс проверки данных.
- `docs/ROADMAP.md` — этапы и критерии приёмки.

GitHub Actions не включён автоматически: команды проверки запускаются локально; workflow доступен вручную, чтобы не расходовать минуты без необходимости.
