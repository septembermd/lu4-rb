# LU4 RB

## Быстрый локальный запуск (Windows / Docker Desktop)

```powershell
docker compose up --build -d
```

После первого запуска: сайт http://localhost:5173, API http://localhost:3001/health. Docker создаёт PostgreSQL, применяет миграции и импортирует карту боссов. Данные сохраняются при обычном `docker compose down`. Для первого ключа доступа см. [docs/LOCAL-DOCKER.md](docs/LOCAL-DOCKER.md).


Закрытая разведка рейдовых боссов для кланов LU4: карта, ручные таймеры, наблюдения IKAR и подписка на клан.

## Состояние v0.2
Работают локальный React-интерфейс и явно помеченное демо: поиск, фильтр источников, выбор точки, карточка дропа, ручные отметки и расчёт окон. Доступна серверная часть: bearer-сессии, PostgreSQL с RLS, ручные отметки с исправлением/отменой/аудитом и приём наблюдений агентов. Кнопка «Подключить API» переключает интерфейс на реальные серверные данные.

Подготовлены миграция PostgreSQL, валидатор каталога, спецификация IKAR и план реализации.
Реальная карта/справочник ещё не импортированы (источник вернул 403). Полноценный пользовательский логин, биллинг, очередь проверок и IKAR-адаптер пока не реализованы; для технического пилота используются временные сессии оператора. Не использовать для продажи production-доступа.

## Локальный запуск
Node.js 24+.

```sh
npm ci
npm run dev
```

Открыть адрес Vite. Кнопка «Проверить демо» включает синтетические данные. Отметки остаются только в памяти вкладки. Текущее время отображается в часовом поясе браузера, доменные даты передаются в UTC.

```sh
npm test
npm run build
```

## Структура
- `src/domain` — типы, таймеры и правила доступа, используемые будущим API.
- `src/data/demo.ts` — исключительно синтетические fixtures.
- `db/001_initial.sql` — основа постоянного хранения; приватные таблицы default-deny RLS, runtime-политики добавлены миграцией 002.
- `docs/DECISIONS.md` — согласованные правила продукта.
- `docs/IKAR-API.md` — контракт будущего агента.
- `docs/DATA-IMPORT.md` — источники и процесс проверки данных.
- `docs/ROADMAP.md` — этапы и критерии приёмки.

GitHub Actions не включён автоматически: команды проверки запускаются локально; workflow доступен вручную, чтобы не расходовать минуты без необходимости.
